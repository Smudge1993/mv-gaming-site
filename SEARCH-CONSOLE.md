# Google Search Console setup

This build includes:

- `sitemap.xml`
- `robots.txt`
- canonical URLs on all five public HTML pages

## Live addresses after upload

- https://mvgaming.org/sitemap.xml
- https://mvgaming.org/robots.txt

## Recommended Search Console property

Choose **Domain** and enter:

`mvgaming.org`

Google will provide a TXT verification record. Add that record in the
Squarespace domain DNS settings without removing the existing GitHub Pages
records.

After verification, open **Sitemaps** in Search Console and submit:

`sitemap.xml`

Use URL Inspection to request indexing for the homepage and the four subpages.
